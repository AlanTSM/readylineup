Para que las alineaciones se descarguen con el nombre correcto, es importante no tener alineaciones antiguas en la carpeta "Descargas" del ordenador.

Instrucciones para descomprimir el archivo ZIP:
Windows: Haz clic derecho en el archivo ZIP y selecciona "Extraer todo". Elige la carpeta donde tengas el simulador como carpeta de destino. De este modo las nuevas alineaciones y plantillas sobreescribirán las antiguas.
